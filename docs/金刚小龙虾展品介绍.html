ClawShell 安全代理

语言 Rust（高性能、内存安全）
双 Agent 模式 同时适配 OpenClaw 和 Hermes，前端可切换视图
虚拟密钥隔离 Agent 使用虚拟密钥，真实 API Key 由 ClawShell 托管
DLP 敏感数据过滤 SSN / 卡号 / 手机号自动识别与拦截
系统服务 端口 21789，配置路径 /etc/clawshell/clawshell.toml
上游配置 DashScope（阿里云）· OpenRouter · Anthropic · MiniMax
配置：CLAWSHELL_BASE_URL=http://127.0.0.1:21789
前端提供独立管理页面，实时显示代理状态与双 Agent 连接状态
