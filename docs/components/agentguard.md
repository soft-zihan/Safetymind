# AgentGuard — 零信任安全框架

> 面向 AI 智能体的零信任安全防护框架，在 LLM 调用前后及工具执行前后进行安全风险识别与拦截，同时支持事后审计。

**语言**：Python  
**许可**：GPLv3  
**适配**：LangChain / AutoGen / OpenAI Agents SDK / LangGraph / LlamaIndex / Dify / OpenClaw

---

## 核心定位

AgentGuard 是 SafetyMind 的**零信任安全基座**。它的核心思想是：**不信任任何单次工具调用，也不信任跨步骤的行为组合**。通过四阶段干预和攻击链检测，确保 Agent 的每一步操作都在安全护栏内。

---

## 四阶段干预

AgentGuard 在 Agent 执行循环的四个关键节点介入：

```
┌─────────────────────────────────────────┐
│           Agent 执行循环                 │
│                                          │
│  ① LLM 调用前 ─── 输入安全检查          │
│       ↓                                  │
│     LLM 调用                             │
│       ↓                                  │
│  ② LLM 调用后 ─── 输出安全审查          │
│       ↓                                  │
│  ③ 工具调用前 ─── 参数安全检查          │
│       ↓                                  │
│     工具执行                             │
│       ↓                                  │
│  ④ 工具执行后 ─── 结果安全审计          │
│                                          │
└─────────────────────────────────────────┘
```

每个阶段都可以：
- **放行**：检查通过，继续执行
- **拦截**：检测到风险，阻止操作
- **告警**：记录事件，通知管理员

---

## 攻击链检测

AgentGuard 的独特能力——不仅判断单次调用，还能检测**跨步骤攻击链**：

**示例攻击链**：
```
步骤 1: 读取 /etc/passwd        ← 单看无害
步骤 2: 读取 ~/.ssh/id_rsa      ← 单看可疑但不确定
步骤 3: 上传到 external.com     ← 组合判定：数据外传攻击！
```

通过 **Trace Pattern** 机制，AgentGuard 维护一个跨步骤的行为上下文窗口，识别这种"分步执行、组合攻击"的模式。

## 核心功能

### 模块化 Plugin 架构

- 客户端与服务端均支持可插拔插件
- 兼容已有基于规则/模型的安全策略
- 支持热加载和动态配置

### 可视化策略配置

Web 控制台提供：

- 交互式策略配置
- 动态热更新
- 运行时状态监控
- 审计日志查看

### ABAC 访问控制

基于属性的访问控制（Attribute-Based Access Control）：

- DSL 定义策略规则
- 属性级权限管理
- 支持上下文条件（时间、地点、角色等）

### 集中式集群管理

中控架构统一管理分布式智能体：

- 策略统一下发
- 状态集中收集
- 跨 Agent 审计

---

## 技术亮点

- **零信任运行时控制**：不依赖底层模型修改，生产环境友好
- **Trace Pattern 攻击链检测**：跨步骤行为分析，识别组合攻击
- **双层架构**：客户端轻量本地过滤 + 服务端深度检测
- **可插拔 Custom Auditor**：支持事后轨迹审计
