# ClawKeeper — 三层防护框架

> 面向 OpenClaw 自主智能体的综合实时安全框架，通过三层互补架构提供全方位安全防护，被誉为"OpenClaw 的诺顿安全卫士"。

**语言**：TypeScript / JavaScript  
**归属**：OpenClaw 专属（下一版本兼容 Hermes）

---

## 核心定位

ClawKeeper 的设计哲学是**执行与安全解耦**——安全逻辑不嵌入智能体内部，而是通过三个独立层级从不同维度提供防护。这种架构使得安全策略可以独立演进，不影响 Agent 核心逻辑。

---

## 三层架构

```
┌─────────────────────────────────────────────────┐
│                  ClawKeeper                      │
│                                                  │
│  ┌──────────────────────────────────────────┐   │
│  │  Skill 层 — 指令级防护                    │   │
│  │  Markdown 安全策略注入 Agent 上下文        │   │
│  │  零配置，Agent 直接解读执行                │   │
│  └──────────────────────────────────────────┘   │
│                      ↓                           │
│  ┌──────────────────────────────────────────┐   │
│  │  Plugin 层 — 运行时执行器                 │   │
│  │  配置加固 + 威胁检测 + 行为扫描 + 审计    │   │
│  │  覆盖 OWASP ASI 十大风险                  │   │
│  └──────────────────────────────────────────┘   │
│                      ↓                           │
│  ┌──────────────────────────────────────────┐   │
│  │  Watcher 层 — 系统级独立监控              │   │
│  │  解耦于 Agent 逻辑，独立进程运行          │   │
│  │  上下文研判 + 执行干预 + 漂移监控         │   │
│  └──────────────────────────────────────────┘   │
└─────────────────────────────────────────────────┘
```

### Skill 层 — 策略即文档

以结构化 Markdown 定义安全策略，注入智能体上下文：

- `windows-safety-guide` — Windows 系统安全约束
- `feishu-safety-guide` — 飞书等第三方平台安全规则
- 策略即文档，人类可读，Agent 可执行

### Plugin 层 — 运行时拦截

在 Agent 执行过程中进行实时安全检查：

- 配置加固（敏感配置保护）
- 威胁检测（提示注入、凭证泄露、代码注入）
- 行为扫描（异常操作识别）
- 审计日志（操作记录与追溯）
- 一键安全加固

### Watcher 层 — 独立治理

与 Agent 内部逻辑完全解耦的独立监控中间件：

- **上下文研判**：结合多轮对话历史判断意图
- **执行干预**：`continue` / `ask_user` / `stop` 三种决策
- **漂移监控**：检测 Agent 行为偏离预期目标
- **双模式部署**：Remote（只读研判）与 Local（可信加固回滚）
- 支持本地或云端部署

---

## 技术亮点

- **执行-安全解耦**：Watcher 层与 Agent 逻辑完全分离，实现监管分离
- **双模式部署**：Remote 模式只读风险研判，Local 模式可执行加固回滚
- **零配置 Skill 防护**：安全策略即 Markdown，无需复杂配置
- **Fail-closed 策略**：权限存储采用 HMAC-SHA256 完整性保护，默认拒绝
- **自演化威胁情报库**：持续学习和更新威胁模式

## 技术栈

- **语言**：TypeScript / JavaScript (Node.js)
- **策略引擎**：Markdown 策略解析与注入
- **Shell**：PowerShell / Bash 脚本
- **测试**：Vitest
- **工作区**：pnpm workspace
- **完整性保护**：HMAC-SHA256
- **部署**：Docker
