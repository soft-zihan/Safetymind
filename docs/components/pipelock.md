# Pipelock — AI Agent 防火墙

> 面向 AI Agent 的开源出站安全防火墙，实现可验证出站控制（VEC），防止密钥泄露、提示注入和 SSRF 攻击。

**语言**：Go  
**部署**：单二进制，零依赖  
**许可**：开源

---

## 核心定位

Pipelock 解决一个关键问题：**Agent 持有密钥但没有网络权限，Pipelock 有网络权限但没有密钥**。这种能力分离（VEC）确保即使 Agent 被攻破，攻击者也无法同时获得密钥和网络访问能力。

---

## 核心功能

### 11 层 URL 扫描管线

对 Agent 的每一个出站请求进行深度检测：

- DLP 模式匹配：65 种凭据特征（API Key、Token、密码等）
- 路径熵分析：检测可疑 URL 结构
- SSRF 防护：阻止内网访问
- DNS 重绑定防御：防止 DNS 欺骗

### 双向 MCP 代理

扫描 MCP 工具请求与响应：

- 检测工具投毒（恶意工具定义）
- 检测调用链攻击（多步骤组合利用）
- 工具响应安全检查

### 响应注入检测

6 轮文本归一化流水线，覆盖 29 种提示注入模式：

- Unicode 归一化
- 编码解码（Base64、URL、HTML）
- 空白字符清理
- 同形字替换
- 模式匹配

### 进程沙箱

基于操作系统级隔离：

- **Linux**：Landlock + seccomp + netns（零特权隔离）
- **macOS**：sandbox-exec

### 其他安全特性

- **紧急 kill switch**：一键停止所有 Agent 网络活动
- **飞行记录器**：Ed25519 签名哈希链日志，防篡改审计
- **金丝雀令牌**：诱饵凭据检测泄露
- **Learn-and-Lock**：行为合约机制，学习正常行为后锁定
- **BIP-39 助记词检测**：阻止加密货币助记词外传
- **区块链地址投毒防护**：检测地址替换攻击

## 技术亮点

- **VEC 可验证出站控制**：能力分离架构，Agent 和 Pipelock 各持有一半能力
- **中介信封（RFC 8941）**：实现跨联邦信任，支持多 Agent 协作场景
- **签名操作凭证（Action Receipt）**：每个操作生成可独立验证的签名凭证
- **单二进制零依赖**：Go 编译，部署极简
